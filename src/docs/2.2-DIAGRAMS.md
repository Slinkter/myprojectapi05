## 1. Propósito

Este documento contiene diagramas detallados que ilustran la arquitectura, el flujo de datos y la secuencia de interacción del proyecto **GitHub Explorer**.

## 3. Diagrama de Flujo de Datos (Data Flow)

Representa el viaje completo de una "búsqueda" a través de las capas FSD del proyecto.

```text
           ( INTERACCIÓN )
           [  USUARIO   ]
                 |
                 | (1) Ingresa texto y pulsa Enter
        _________V_________
       /                   \
      /    [ CAPA UI ]      \  <-- SearchBar.jsx
     /   (Componente)        \      (Captura el evento onSearch)
    /_________________________\
                 |
                 | (2) Emite evento
        _________V_________
       /                   \
      / [ CAPA ORQUESTADORA ]\  <-- UserSearchPage.jsx
     /      (Página)         \      (Recibe onSearch)
    /_________________________\
                 |
                 | (3) Ejecuta búsqueda global
        _________V_________
       /                   \
      / [ CAPA DE ESTADO ]  \  <-- UserSearchContext.jsx
     /     (Contexto)        \      (Administra loading/user/error)
    /_________________________\
                 |
                 | (4) Invoca Hook de Aplicación
        _________V_________
       /                   \
      /  [ CAPA LÓGICA ]    \  <-- useGithubUser.js
     /       (Hook)          \      (Cambia estado a 'loading')
    /_________________________\
                 |
                 | (5) Llama al Caso de Uso (Validación)
        _________V_________
       /                   \
      / [ CAPA DE NEGOCIO ] \  <-- searchUserUseCase.js
     /    (Use Case)         \      (Valida reglas del username)
    /_________________________\
                 |
                 | (6) Solicita a Infraestructura
        _________V_________
       /                   \
      / [ CAPA DE SERVICIO ]\  <-- github.js (Service)
     /     (Infra)           \      (Realiza el Fetch a la red)
    /_________________________\
                 |
                 +-----------> [ GITHUB API (Cloud) ]
                 |                  |
                 +<---------- [ RESPUESTA JSON ]
                 |
                 | (7) Desestructuración O(1) y Validación Zod
                 |
        _________V_________
       /                   \
      /  [ RENDER FINAL ]   \  <-- UserSearchResult.jsx
     /  (Presentación)       \      (Decide qué componente mostrar)
    /_________________________\
          /      |      \
    [UserCard] [Skeleton] [ErrorDisplay]
```

## 4. Diagrama de Secuencias (Sequence Diagram)

   |             |               |               |             |           |          |
   |             |               |--searchUser-->|             |           |          |
   |             |               |               |             |           |          |
   |             |               |               |--Validar()--|           |          |
   |             |               |               |             |           |          |
   |             |               |               |-------------|--FetchUser|          |
   |             |               |               |             |           |          |
   |             |               |               |             |           |---GET--->|
   |             |               |               |             |           |          |
   |             |               |               |             |           |<--JSON---|
   |             |               |               |             |           |          |
